<h1 align="center">Struttura Discord</h1>

<p>
  Esercizio svolto durante il corso Boolean per esercitarmi nella definizione della struttura di una pagina web ispirata al sito di Discord, utilizzando solo blocchi e layout senza contenuti definitivi.
</p>

## Obiettivo

- Riprodurre la struttura base del layout di Discord usando blocchi colorati al posto dei contenuti reali.
- Individuare il layout generale della pagina e procedere dall’alto verso il basso (header, sezioni centrali, footer).
- Non passare alla sezione successiva finché la precedente non è impostata correttamente.
